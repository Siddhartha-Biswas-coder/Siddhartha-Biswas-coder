# 🧩 Frontend Architecture (Current Learning)

I currently follow a clean **4 Layer Frontend Architecture** pattern:

```text
UI Layer
   ↓
Hook Layer
   ↓
State Layer
   ↓
API Layer
```

### 🎨 UI Layer
Responsible for:
- Showing UI
- User Interaction
- Navigation

### 🪝 Hook Layer
Responsible for:
- Business Logic
- Connecting UI & APIs

### 🧠 State Layer
Responsible for:
- Global State
- User State
- Loading State

### 🌐 API Layer
Responsible for:
- Backend Communication
- Axios Requests
- API Handling
